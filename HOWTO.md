# Как запустить Mini App (мини-приложение)

Telegram открывает Mini App только по **https**, поэтому на этапе разработки
нужен бесплатный туннель (cloudflared), который выдаёт https-адрес и пробрасывает
его на локальный сервер бота.

## 🚀 Быстрый способ (одна команда)
После установки cloudflared (шаг 0 ниже) просто запусти:
```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```
Скрипт сам поднимет туннель, впишет адрес в `.env` и запустит бота.
Останавливается по `Ctrl+C` (туннель гасится автоматически).
Дальше открой @assemblyos_bot и нажми «📱 Открыть приложение».

Ниже — тот же процесс вручную, если хочется контролировать каждый шаг.

---

## 0. Один раз: установить cloudflared
```powershell
winget install --id Cloudflare.cloudflared -e --accept-source-agreements --accept-package-agreements
```
После установки закрой и снова открой терминал (чтобы `cloudflared` нашёлся в PATH).

## 1. Запусти туннель (Терминал A)
```powershell
cloudflared tunnel --url http://localhost:8080
```
В выводе найди строку с адресом вида:
```
https://random-words-here.trycloudflare.com
```
Скопируй его.

## 2. Впиши адрес в .env
```
WEBAPP_URL=https://random-words-here.trycloudflare.com
```
(порт менять не нужно — сервер бота слушает 8080)

## 3. Запусти бота (Терминал B)
```powershell
python bot.py
```
Должны появиться строки логов и `Mini App сервер: http://127.0.0.1:8080`.

## 4. Проверь в Telegram
Открой @assemblyos_bot → нажми кнопку **«📱 Открыть приложение»**
(или кнопку-меню «Platforma» слева от поля ввода).
- **Админ** видит форму «Новое задание» + список всех задач.
- **Работник** видит только назначенные ему задания с кнопкой «Выполнено».

## Важно
- **Оба терминала** (туннель и бот) должны работать одновременно.
- Бесплатный адрес `trycloudflare.com` **меняется при каждом перезапуске туннеля** —
  тогда снова обнови `WEBAPP_URL` в `.env` и перезапусти `python bot.py`.
- Для постоянного адреса нужен свой домен (именованный туннель Cloudflare) или хостинг.
- Чтобы работник появился в списке для назначения — он должен хотя бы раз
  открыть бота (`/start`) или само приложение.
