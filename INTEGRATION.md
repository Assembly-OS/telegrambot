# Интеграция бота с платформой Assambleya OS

Бот теперь работает **на той же базе**, что и веб-платформа (Next.js): одни
пользователи, одни задачи. Своей отдельной БД у бота больше нет.

## Что изменилось
- **Общая БД.** Бот читает/пишет `../data/assambleya.db` (путь можно переопределить
  `PLATFORM_DB`). Задача, выданная в боте, сразу видна в веб-интерфейсе, и наоборот.
- **Привязка аккаунта.** В боте: `/link ЛОГИН ПАРОЛЬ` — бот проверяет пароль через
  login-API платформы и связывает Telegram с учётной записью (столбец `users.telegram_id`).
  Сообщение с паролем бот сразу удаляет.
- **Роли — из платформы.** Руководители (RAIS, BOLIM_RAHBARI, AI_LAB, UYUSHMA_RAISI,
  LOYIHA_RAHBARI) в боте видят «Дать задание» / «Все поручения». Остальные — только свои.
  Старое `/admin_login` убрано.
- **Задачи — по-настоящему.** «Дать задание» создаёт задачу платформы (код `T-XXXX`,
  статус `YANGI`, отдел, событие). «Выполнено» = сдать на проверку (`→ TEKSHIRUVDA`),
  дальше автор принимает в веб-интерфейсе. Направления = отделы (GR/FR/BR/PR/AI_LAB),
  проекты — из таблицы `loyihalar`.
- **Mini App = платформа.** Кнопка «Открыть приложение» и меню-кнопка открывают
  `PLATFORM_URL` (весь веб-интерфейс Assambleya OS).
- **Пуши из веб-интерфейса.** Когда задачу выдают в вебе, платформа шлёт боту на
  `/notify`, и исполнителю приходит сообщение в Telegram (если он сделал `/link`).

## Настройка

### 1. Зависимости бота
```bash
cd bot
python -m venv .venv && . .venv/Scripts/activate   # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 2. `.env` бота (скопируйте из `.env.example`)
```
BOT_TOKEN=...                       # от @BotFather
PLATFORM_URL=https://<туннель>      # публичный https платформы (Mini App)
PLATFORM_API=http://127.0.0.1:3000  # локальный адрес платформы (для /link)
BOT_NOTIFY_SECRET=<любая-строка>    # общий секрет для пушей из веба
# PLATFORM_DB=../data/assambleya.db # по умолчанию и так рядом
```

### 3. Окружение платформы (в корне проекта, файл `.env.local`)
```
BOT_NOTIFY_URL=http://127.0.0.1:8080/notify
BOT_NOTIFY_SECRET=<тот-же-секрет-что-в-боте>
```
Без этих переменных платформа работает как обычно, просто не шлёт Telegram-пуши.

## Запуск (три процесса)
```bash
# 1) Платформа
npm run dev                                   # http://localhost:3000

# 2) Туннель для Mini App (нужен https), адрес -> PLATFORM_URL в .env бота
cloudflared tunnel --url http://localhost:3000

# 3) Бот
cd bot && python bot.py
```

## Первый вход в боте
1. `/start` → бот попросит привязать аккаунт.
2. `/link rais 12345678` (свой логин/пароль платформы).
3. Готово: руководитель видит «Дать задание» и «Все поручения», исполнитель — «Мои задания».

> `webapp/index.html` больше не используется (Mini App — это сама платформа) и
> оставлен только для истории. Веб-сервер бота теперь обслуживает лишь `/notify` и `/healthz`.
